Command Consider the following rs.printReplicationInfo() output: configured oplog size '191513 MB' --- log length start to end '75894 secs (21.08 hrs)' --- oplog first event time 'Thu Aug 19 2021 14:41:25 GMT+0100 (Irish Standard Time)' --- oplog last event time 'Fri Aug 20 2021 11:46:19 GMT+0100 (Irish Standard Time)' --- now 'Fri Aug 20 2021 11:46:22 GMT+0100 (Irish Standard Time)' Select the statement(s) that apply to the rs.printReplicationInfo() output above: Check all that apply:

题目选项

  1. A．
    The oplog is configured for 48 hours coverage
  2. B．
    The day of the first oplog event is Thu Aug 19 2021
  3. C．
    The oplog details in the output only refer to the node on which the command was run

答案置信度：高

正确答案：B、C

解析语言：中文

rs.printReplicationInfo() 打印的是执行该命令的那个成员自身的 oplog 信息（定义即“prints a formatted report of the replica set member's oplog”），所以 C 正确；输出中 oplog first event time 为 Thu Aug 19 2021，B 正确。configured oplog size 是 191513 MB（容量上限），而 log length 只有 75894 秒（约 21.08 小时），说明当前 oplog 只覆盖约 21 小时，A 的“配置为 48 小时覆盖”错误。
