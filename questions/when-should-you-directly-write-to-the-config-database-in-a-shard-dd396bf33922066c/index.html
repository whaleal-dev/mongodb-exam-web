52. When should you directly write to the config database in a sharded cluster? Check all that apply:

题目选项

  1. A．
    When directed to do so by MongoDB Support staff
  2. B．
    When directed to do so by MongoDB Documentation
  3. C．
    When you need to change the shard key

答案置信度：中

正确答案：A、B

解析语言：中文

config 库由集群自身维护，应用原则上不应直接写入，只有在 MongoDB 官方支持人员明确指引或官方文档给出的流程要求时才可为之，A、B 正确。需要修改分片键应使用 refineCollectionShardKey 等 sharding 命令（或重建集合/重新分片），绝不能直接去改 config 库，C 错。
