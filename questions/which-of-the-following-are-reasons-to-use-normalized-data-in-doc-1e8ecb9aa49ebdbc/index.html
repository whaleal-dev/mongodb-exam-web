63. Which of the following are reasons to use normalized data in documents instead of embedding data in documents? Check all that apply:

题目选项

  1. A．
    allows for easier modeling of large hierarchical data sets.
  2. B．
    stores data in separate collections when embedding it in a document decreases read performance particularly when the majority of data may be not frequently used.
  3. C．
    allows for complex many-to-many relationships to more easily modelled.
  4. D．
    allows for data to be updated in a single atomic write.
  5. E．
    allows for modeling one-to-many relationships with a high arity with large documents on the many side of the relationship.

答案置信度：中

正确答案：B、C、E

解析语言：中文

引用（规范化）的典型理由有三个：把体积大又不常访问的数据拆到独立集合，避免每次读主文档都一起拉回来（B）；更好地建模多对多关系（C）；以及多端文档很大或数量无上限（高基数）的一对多关系（E）。A 与 D 恰恰是内嵌的理由——层级数据内嵌更好建模，单文档内嵌可一次原子写完成更新。
