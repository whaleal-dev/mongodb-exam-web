6. Consider a collection called sample where you created an indexes with the following command: db.user.createIndex( { "username" : -1 } ) db.user.createIndex( { "group" : -1 } ) And where all the documents had the following fields: { "_id": ObjectId("5360c0a0a655a60674680bbc"), "username": "ken1972", "group": "admin" } For which of the following update queries will MongoDB use the group index when performing the update query? Check all that apply:

题目选项

  1. A．
    db.user.update( { username: "ken1972" }, { $set: { group: "user" } }, { multi: true, hint: { group: 1 } } )
  2. B．
    db.user.update( { username: "ken1972" }, { $set: { group: "user" } }, { multi: true }, { hint: { group: 1 } } )
  3. C．
    db.user.update( { username: "ken1972" }, { $set: { group: "user" } }, { multi: true, hint: { username: 1 } } )

答案置信度：中

正确答案：A

解析语言：中文

只有 A 把 hint 放在 update 的选项文档（第 3 个参数）里并指向 group 索引，因此这次更新会按提示使用 {group:-1} 索引。B 的 hint 指向 username 索引，走的是 username 索引；C 把 hint 当作第 4 个参数传入（旧接口那里是 multi/回调的位置），hint 会被忽略，仍然走 username 索引。
