To ensure that write operations are not lost in the event of a server failure, WiredTiger: Check all that apply:

题目选项

  1. A．
    records all data manipulation operations in an operations log, oplog
  2. B．
    buffers write operations in memory and flushes them frequently to create data checkpoints
  3. C．
    uses a write-ahead logging system to an on-disk journal file

答案置信度：中

正确答案：B、C

解析语言：中文

WiredTiger 先把修改写入预写日志（journal）落盘，崩溃后靠日志重放恢复，这是保证写入不丢的核心机制（A）；同时它把写缓存在内存中，并周期性（默认 60 秒）做 checkpoint 把数据固化到数据文件、缩短恢复时间（C）。B 说的是复制用的 oplog，属于复制机制而非存储引擎的持久化手段（oplog 自身也要依赖 journal 持久化）。
