17. You have created the following index on the travel collection: db.travel.createIndex( { "name" : 1, "age" : -1, "visited" : 1 } ) Which of the following queries will be able to fulfill the query without an in-memory sort (i.e., it's able to use the index to sort)? Check all that apply:

题目选项

  1. A．
    db.travel.find( { "name": "Randy Salazar" } )
  2. B．
    .sort( { "age": -1 } )
  3. C．
    db.travel.find( { "age" : { "$gt": 22 } } )
  4. D．
    .sort( { "visited": -1 } )
  5. E．
    db.travel.find( {"name": "Lillian Hernandez", "visited" : /^I/ } )
  6. F．
    .sort( { "age": 1} )

答案置信度：低

正确答案：A、B、E、F

解析语言：中文

源文档把选项按行拆成了 6 项，它们实际是三组查询：(A)+(B) 是 find({ "name": "Randy Salazar" }).sort({ "age": -1 })；(C)+(D) 是 find({ "age": { "$gt": 22 } }).sort({ "visited": -1 })；(E)+(F) 是 find({ "name": "Lillian Hernandez", "visited": /^I/ }).sort({ "age": 1 })。对索引 { "name": 1, "age": -1, "visited": 1 } 而言，第 1 组有 name 等值前缀且排序方向与索引一致，可直接用索引提供有序结果；第 3 组 name 等值、排序字段 age 位于范围字段 visited 之前（符合 ESR），单个排序字段可用反向遍历满足，同样不需要内存排序；第 2 组既无 name 等值前缀，又用 age 做范围、visited 做排序，必须内存排序。故组成第 1、3 组的 A、B、E、F 为答案（题面被拆行破坏，故置信度低；若还原为原题三选项版本，等价于选第 1 组与第 3 组两条查询）。
