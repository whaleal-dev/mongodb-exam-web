MongoDB DBA · Question 397 · Multiple choice

which of the following statements are true about roles in MongoDB? Check all that apply:

Answer options

  1. A．
    Roles are defined as actions on a resource
  2. B．
    User-defined roles created on one database can be inherited by user-defined roles created on other databases
  3. C．
    User-defined roles can inherit built-in roles

Answer confidence: High

Correct answer: B, C

Explanation language: Chinese

用户自定义角色既可以继承内置角色，也可以继承其它数据库上定义的（用户自定义或内置）角色——只需在 roles 数组里用 db 指明来源库，所以 B、C 都对。A 表述不准确：权限才是“资源 + 操作”的组合，角色是权限的集合，说“角色被定义为对资源的操作”混淆了角色与权限两个概念。
