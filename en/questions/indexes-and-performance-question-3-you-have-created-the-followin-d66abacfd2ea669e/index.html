Indexes and Performance: Question 3 You have created the following index on the travel collection: db.travel.createIndex( { "name" : 1, "age" : -1, "visited" : 1 } ) Which of the following queries will be able to fulfill the query without an in-memory sort (i.e., it's able to use the index to sort)? Check all that apply:

Answer options

  1. A．
    db.travel.find( { "name": "Randy Salazar" } ) .sort( { "age": -1 } )
  2. B．
    db.travel.find( { "age" : { "$gt": 22 } } ) .sort( { "visited": -1 } )
  3. C．
    db.travel.find( {"name": "Lillian Hernandez", "visited" : /^I/ } ) .sort( { "age": 1} )

Answer confidence: High

Correct answer: A, C

Explanation language: Chinese

索引为 { name: 1, age: -1, visited: 1 }：A 在 name 上等值、按 age 排序，排序键正好是等值字段之后的索引前缀且方向一致，可用索引排序；C 在 name 上等值、visited 上是范围（正则 /^I/），排序键 age 位于范围字段之前，仍符合 ESR（等值—排序—范围）形态，可用反向索引扫描完成排序。B 的过滤字段 age 不是最左前缀、排序字段 visited 又排在更后面，无法用索引排序，必须做内存排序。
