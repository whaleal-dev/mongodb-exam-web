53. Consider a collection called reviews which consists of documents with the following fields: product_name (string) this field is not unique as there are several products with the same prefix product_id (ObjectId) this field has several duplicates as popular products get more reviews review (string) almost unique across all documents, only a few duplicate values reviewer_id (string) this field has a few values that are in many document for frequent reviewers, these are the exception as most people only give a few reviews rating (integer) this field contains a value from 1 to 5 reviewed_at (Timestamp) almost unique across all documents, only a few duplicate values _id (ObjectId) automatically created on insert, unique across all documents Which of the following shard keys below is the best of those listed to support queries on the reviews collection? Choose the best answer:

Answer options

  1. A．
    { reviewed_at: 1, product_name: 1}
  2. B．
    { product_id: 1, _id: 1}
  3. C．
    { reviewer_id: 1, reviewed_at: 1}

Answer confidence: Medium

Correct answer: A

Explanation language: Chinese

选分片键最看重首字段的基数与频度：reviewed_at 几乎唯一（基数与文档数同量级），配合 product_name 可持续分裂出大小均匀的 chunk。reviewer_id 属于"少数值覆盖大量文档"的低基数/高频字段，作前缀容易造成倾斜和不可分裂的大 chunk；product_id 重复较多，热门商品会把写入与新 chunk 集中到同一范围（另有源卷把 {reviewer_id, reviewed_at} 记为答案，但按基数与频度分析 {reviewed_at, product_name} 更优）。
