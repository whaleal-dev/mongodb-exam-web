59. Which of the following types of data are stored in the Config DB? Check all that apply:

Answer options

  1. A．
    Details on the mongos routing processes present in the cluster.
  2. B．
    Information on each collection in each database, whether sharded or not.
  3. C．
    Details on the users and privileges for each collection and database.
  4. D．
    The changes to the metadata on the shard data.

Answer confidence: Medium

Correct answer: A, D

Explanation language: Chinese

config 库存放分片集群的元数据：config.changelog 记录元数据（chunk 迁移、切分等）变更，config.mongos 为每个 mongos 路由进程保存一条记录，所以 B、C 正确。A 错在 config.collections 只为已分片的集合建条目，未分片集合不在其中；D 实际存放在 admin 库（分片集群里由 config server 承载 admin 库），并不在 config 库本身，源卷把 D 当答案属于误记（同一题在不确定的题目卷里也没给出答案）。
