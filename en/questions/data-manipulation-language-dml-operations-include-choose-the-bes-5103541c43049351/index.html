MongoDB DBA · Question 549 · Single choice

Data manipulation language (DML) operations include: Choose the best answer:

Answer options

  1. A．
    Read operations
  2. B．
    Cluster configuration
  3. C．
    Write operations
  4. D．
    Index creation
  5. E．
    User creation

Answer confidence: Medium

Correct answer: C

Explanation language: Chinese

按 MongoDB 官方 SQL 对照表，DML 指对数据的写操作（insert/update/delete），所以“写操作”C 正确。A 用户创建属安全/管理（DCL 侧），B 索引创建属 DDL，E 集群配置属管理操作；D 的读操作在官方对照里单列为 DQL（查询），因此不是本题“最佳答案”。
