Aggregation: Question 10 Consider a collection places that only contains the following documents: { "_id": 0, "city": "New York", "state": "NY", "zip": 10001, "county": "New York" } { "_id": 1, "city": "New York", "state": "NY", "zip": 11211, "county": "Kings" } { "_id": 2, "city": "New York", "state": "NY", "zip": 10036, "county": "New York" } { "_id": 3, "city": "Albany", "state": "NY", "zip": 12224, "county": "Albany" } You perform the following aggregation operation against the places collection: db.places.aggregate([ { $group: { _id: { city: "$city", state: "$state" }, county: { $addToSet: "$county" }, zips: { $addToSet: "$zip" } } } ]) Which of the following represents the output of this operation? Choose the best answer:

Answer options

  1. A．
    { "_id": { "city": [ "Albany"], "state": [ "NY" ] }, "county": [ "Albany" ], "zips": [ 12224 ] } } { "_id": { "city": [ "New York" ], "state": [ "NY" ] }, "county": [ "Kings", "New York" ], "zips": [ 10036, 11211, 10001 ] } }
  2. B．
    There will be no documents in the result set

原答案 A 不可能成立：$group 的 _id 是分组键表达式，{ city: $city, state: $state } 求值后得到的是标量值子文档（_id: { city: Albany, state: NY }），$addToSet 只作用在 county 和 zips 上，_id 里出现数组毫无来源。因此正确形态是 E，且同一题的另一份源卷（1-DEV / 李和平卷）记录的答案正是 E。C 把 city/state 当成重复 push 的数组，D 完全没有聚合，B 更不可能。
