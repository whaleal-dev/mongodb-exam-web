MongoDB DBA · Question 21 · Multiple choice

21. Consider the following mongod configuration file: storage: dbPath: /data/db systemLog: destination: file path: "/data/logs" replication: replSetName: "RS-0" net: bindIp: "127.0.0.1,192.168.0.100" Which of the following are true when running a mongod server with the above configuration file, when no other command line arguments are passed to this server instance? Check all that apply:

Answer options

  1. A．
    Data files will be stored in server path /data/db
  2. B．
    Log messages will be sent to SYSLOG
  3. C．
    The mongod instance will listen to incoming requests on port 27017

Answer confidence: High

Correct answer: A, C

Explanation language: Chinese

storage.dbPath: /data/db 决定数据文件位置（A 对）；systemLog.destination: file 表示日志写文件而不是 SYSLOG（B 错）；net 段没有指定 port，mongod 默认监听 27017（C 对）。配置里的 replSetName 只说明它以副本集成员身份启动，与监听端口无关。
