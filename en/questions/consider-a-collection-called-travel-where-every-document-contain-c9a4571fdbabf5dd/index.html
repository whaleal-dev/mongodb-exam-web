8. Consider a collection called travel where every document contains the following fields: { "_id" : ObjectId("5ab0615f5b3e785dd5fa3705"), "name" : "Randy Salazar", "age" : 60, "visited" : [ "Israel", "São Tomé and Príncipe", "Malta", "Ethiopia" ] } You create the following index on travel: db.travel.createIndex({ "name": 1, "age": 1 }) After creating this index, which of the following queries will be fully covered queries? Check all that apply:

Answer options

  1. A．
    db.travel.find({ "name": /^N/ } }, { "name": 1, "age": 1 })
  2. B．
    db.travel.find({ "age": { "$gt": 18 } }, { "visited": 0, "_id": 0 })
  3. C．
    db.travel.find({ "name": "Randy Salazar", "age": 60 }, { "name": 1, "_id": 0 })
  4. D．
    db.travel.find({ "name": "Randy Salazar" }, { "age": 1, "_id": 0 })
  5. E．
    db.travel.find({ "age": { "$ne": 12 } }, { "name": 1, "age": 1, "_id": 0 })

Answer confidence: High

Correct answer: C, D

Explanation language: Chinese

覆盖查询要求过滤字段和投影返回字段都在同一个索引里，并且必须显式排除 _id（_id 不在 {name:1,age:1} 中）。C 用 name+age 等值过滤、只返回 name 并排除 _id；D 用 name 前缀等值过滤、只返回 age 并排除 _id，两者都完全由该索引满足。A 没有排除 _id（且语句多了一个花括号），返回的 _id 必须回表；B 的过滤条件只落在复合索引第二列 age 上、缺少前缀 name，无法用索引定位，投影里还要排除索引外的 visited；E 的 $ne 同样落在第二列，属不可用索引边界的条件，所以都不算覆盖查询。
