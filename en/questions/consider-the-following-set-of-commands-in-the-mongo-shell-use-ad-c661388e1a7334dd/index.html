Consider the following set of commands in the mongo shell: use admin db.setLogLevel(5, "index") Which of the following statements is true after the logging level is changed by the above command? Choose the best answer:

Answer options

  1. A．
    Debug messages will be indexed in the log file
  2. B．
    Queries that require index access will be logged
  3. C．
    Only indexes created in the admin database will be logged
  4. D．
    Index management commands will be logged with debug severity
  5. E．
    Queries taking over 5 milliseconds will be logged with the index the used
  6. F．
    [图片]

Answer confidence: High

Correct answer: D

Explanation language: Chinese

db.setLogLevel(5, "index") 是把 index 这个日志组件的详细度调到 5（debug），因此与索引相关的管理/操作会以 debug 级别写进日志（D）。它按组件生效而不是按数据库生效（A 错），不是给日志建索引（B 错），也与 5 毫秒的慢查询阈值无关（C 错）。 考生批注：可能为d
