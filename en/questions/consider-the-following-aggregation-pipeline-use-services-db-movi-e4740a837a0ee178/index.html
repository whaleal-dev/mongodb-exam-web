56. Consider the following aggregation pipeline: use services db.movies.aggregate([ { "$project": { "avgScore": { "$sum": "$reviews.rating" } } }, { "$out": "ratings" } ]) If this pipeline is run against a sharded collection, where will the $out stage take place? Choose the best answer:

Answer options

  1. A．
    The mongos
  2. B．
    Each individual shard
  3. C．
    The primary shard
  4. D．
    The shard containing documents with the highest avgRating values
  5. E．
    A random shard

Answer confidence: High

Correct answer: C

Explanation language: Chinese

官方文档（Aggregation Pipeline and Sharded Collections）明确：多分片执行时结果通常送到 mongos 合并，但如果管道含 $out（或 $lookup）阶段，合并改在 primary shard 上进行，所以 $out 在 primary shard 执行，选 C。A（mongos）是一般管道的合并位置，正是这里要排除的例外；B、D、E 无依据。
